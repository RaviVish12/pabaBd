# Pamoditha's Birthday Journey (flat version: no folders)

Every file is in ONE folder, so you can select them all and upload in one go
(GitHub: Add file > Upload files > select all > Commit). `index.html` must end up in the repo's top level.

To swap a picture/video: upload a new file with EXACTLY the same name (it replaces the old one).
Names are case-sensitive on GitHub: `stop1-photo1.jpg` works, `Stop1-Photo1.JPG` does not.

stop1-forest.mp4 / stop1-poster.jpg / stop1-photo1..3.jpg
stop2-sea.mp4 / stop2-poster.jpg / stop2-photo1..3.jpg
stop3-mountains.mp4 / stop3-poster.jpg / stop3-photo1..3.jpg
stop4-island.mp4 / stop4-poster.jpg / stop4-photo1..3.jpg
birthday-music.mp3

Words, places and colours: edit `config.js`.
